# Key pre-native product decisions

1. Update queue is the primary real-time contribution.
2. Start wait timer is optional stronger evidence; it is not required for community usefulness.
3. Native v1 avoids always-on background GPS.
4. The existing React/Vite product is reused through Capacitor rather than rewritten.
5. ODA address chunks stay remotely hosted/static rather than bundled into native binaries.
